# Digital Trend Media

Landing page for Digital Trend Media — Erklärfilme, die komplexe Angebote verständlich machen.

Built from a Paper design with Next.js, Tailwind CSS, and deployed on Vercel.

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS v4
- Vercel
